# From Browser to Production 📚

My learning notes: the complete journey of a request from a user's browser to a production server.

```
User Browser → DNS → Internet → Firewall → Load Balancer → NGINX
→ Application Server → Spring Boot API → Database → Cache → Response → Browser
```

## How to use this course

1. Read one phase's notes (`.md` or `.pdf` — same content, PDF sits next to the Markdown).
2. Do the **LAB** section hands-on.
3. Solve the **ASSIGNMENT** at the end of the chapter and submit answers to Claude for review/exam.
4. Only then move to the next phase. Update the progress table below.
